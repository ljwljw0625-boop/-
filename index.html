      최신 주요뉴스 붙여넣기
      토스증권 → 피드 → 뉴스 → 주요뉴스 화면에서 Ctrl+A, Ctrl+C 로 복사해 아래에 붙여 넣으세요. 여러 페이지를 이어 붙여도 됩니다(중복 제거). "N시간 전"은 붙여 넣은 시각 기준으로 계산합니다.
      뉴스 점수 = 헤드라인 재료 강도(대형 계약·최대 실적 +, 급락·악재 −, 명세 4.11 긍정/부정어) × 토스 노출 순서 × 최신성. 종합 = 뉴스 점수 + 실시간 타점 점수(관심종목에 있을 때). 규칙 기반 참고 분석이며 매수 추천이 아닙니다.

      주요뉴스 중요도 순 0

      중요도 = 재료 강도(|점수|+1) × 최신성(24시간에 절반) × 토스 노출 순서, 시장 전체 뉴스(지수·금리·환율·유가·선거 등) ×1.3, 종목이 언급된 뉴스 ×1.2. 빨강 = 호재, 파랑 = 악재, 회색 = 중립.

      매크로 지표 –

      일간 = 토스 하단 지표 바의 실제 지수(달러 인덱스·S&P500·나스닥, 예약 작업이 30분마다 읽음). 없으면 대체 ETF의 전일 종가 대비. 실시간 = 대체 ETF(현재가 API) 30분 변화. WTI는 USO, 10년물 금리는 IEF로 봅니다(IEF가 오르면 금리는 내림). 영향 점수 = 지표마다 우호 +1 · 중립 0 · 악영향 −1의 합 → +2 이상 우호, −2 이하 위험 회피. 주요뉴스 시장 분위기와 07:00·15:00 종목 추천에 반영합니다.
      토스증권 Open API 현재가(읽기 전용)를 모아 만든 분봉과 규칙 기반 기술적 지표를 활용한 참고용 시각화이며, 투자 자문이나 매매 추천이 아닙니다. 주문 기능은 없습니다.
